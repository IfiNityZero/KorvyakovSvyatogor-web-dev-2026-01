## Запуск на компьютере

Для лабораторных с динамическим меню нужен локальный веб-сервер, чтобы браузер мог загрузить JSON-файл. Из корня проекта можно запустить:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000/ . Если установлен Docker, можно запустить проект командой `docker compose up --build`; сайт будет доступен на http://localhost:8080/ .
